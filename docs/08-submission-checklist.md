# 08 · Submission checklist

Use [00-hackathon.md](00-hackathon.md) and the [official rules](https://nebiusglobalaihackathon.devpost.com/rules). Empty boxes remain unverified.

## Required submission

- [ ] Working Personal AI flow uses Nemotron on Token Factory; persistent Kin memory, one reusable scheduled skill and controlled tools survive restart.
- [ ] D0-selected photo extraction path actually works; exact model/provider and optional dedicated deployment are disclosed.
- [ ] Authenticated policy checks cover retrieval, history, summaries, source attachments and delivery; minimum adversarial tests pass.
- [ ] Private intake requires caregiver confirmation before a schedule activates; no diagnosis, dosing, interaction inference or silent conflict resolution.
- [ ] Self-service synthetic demo lets judges complete both Family and Admin steps, including sharing, without waiting for the entrant.
- [ ] Public licensed source/assets, verified setup README, description, track and platform feedback supplied.
- [ ] Public YouTube video targets 2:50, shows working minimum features and English translations for Mandarin output; included third-party material is authorized.
- [ ] Eligibility/representative and any prior-project updates checked; Upgradient is a substantially different submission.
- [ ] Stable demo/test-build URL, testing credentials/instructions and reset procedure verified; free access through **16 Dec 2026, 04:00 SGT**.

## Product and bonus checks

- [ ] Each Telegram tester starts a DM with the bot; IDs/roles are verified before restricted data is available.
- [ ] Judge runs are isolated; synthetic role switching cannot grant roles in a real family workspace.
- [ ] Only fictional data is used; full documents, raw audit queries and filesystem paths are not exposed through lower-role views.
- [ ] Data flow explicitly includes Telegram transport and approved inference to Nebius; no claim that all data remains local.
- [ ] Tavily makes a runtime lookup using a validated public-only query and locale domain list.
- [ ] City selected only for an attended event.
- [ ] Omni/audio, teach-by-chat, digests, viewer expiry, OpenShell and data-map scenes are included only if their gates passed.
- [ ] Keys and family volumes remain uncommitted; judge-period operating budget is reserved.

## Devpost description

Describe confirmed intake, grounded recall, a real reminder and the permission boundary shown in the demo. Caring Village already offers role-based permissions; distinguish Kin's combined chat/document/memory workflow without claiming that role controls are new. Name only actual inference models and deployed isolation services, with known limitations.

## Feedback

For each tool used, report the tested API/configuration, observed result, reproducible sanitized obstacle, suggested change and impact. Distinguish unavailable deployment/modality from extraction quality and distinguish an intended privacy control from a passed enforcement test.
